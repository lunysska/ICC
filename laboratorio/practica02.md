## Descripción 

Completar la implementación de los métodos definidos en la clase Function, desarrollando la lógica necesaria para que cada uno realice correctamente la operación o tarea descrita en su documentación, Javadoc.

Se deberá respetar la firma de cada método (nombre, parámetros y tipo de retorno), así como utilizar estructuras de control, ciclos y operaciones básicas de Java para resolver los problemas planteados.

## Objetivos

Al finalizar la práctica, el estudiante será capaz de:
1. Implementar métodos en Java respetando su definición, parámetros y tipos de retorno.
2. Aplicar estructuras de control condicionales para resolver problemas de lógica.
3. Utilizar ciclos para realizar operaciones repetitivas y procesar información.
4. Manipular números enteros y realizar operaciones aritméticas para resolver problemas.
5. Recorrer y analizar arreglos para obtener información específica de sus elementos.
6. Descomponer problemas en soluciones pequeñas mediante la modularización del código.
7. Identificar y considerar casos particulares y valores límite durante la implementación de algoritmos.
8. Comprobar el funcionamiento de los métodos mediante diferentes casos de prueba.

## Actividad principal

Copia la clase Function.java del almacén con las plantillas e implementa cada método de acuerdo a la descrición en la documentación.

## Entrega

El código debe compilar sin errores.

Los resultados deben poder verificarse mediante pruebas de ejecución.

No se permite modificar las firmas originales de los métodos.

No se permite utilizar métodos de bibliotecas que resuelvan directamente los problemas planteados.

## Consideraciones para la evaluación

La evaluación de cada método se realizará mediante casos de prueba que contemplen entradas ordinarias y casos límite. No será suficiente que el programa compile: cada método deberá producir el resultado esperado para las entradas evaluadas.
